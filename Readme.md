# Flipper Zero App Directory

All repositories owned and created by [@Musicandmyth](https://github.com/Musicandmyth).

## [USB Radio](https://github.com/Musicandmyth/USB_radio_Flipper0)

The USB Radio extension uses USB bridging to connect a PC with an SDR, to be
used as a radio module on the Flipper Zero.

## [Universal Bruteforce](https://github.com/Musicandmyth/flipper-universal-bruteforce)

The Flipper Zero universal bruteforce tool allows any directory to be
bruteforced (by running through every signal in that folder). The folder can
have mixed file types, and the following protocols are supported:

- Sub-GHz
- Infrared
- RFID
- iButton
- NFC
